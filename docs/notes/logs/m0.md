# M0 notes

- **Dead code:** `-O3` deletes work whose result is unused. `benchmark::DoNotOptimize(x)` keeps it.
- **First touch:** the first write to each page faults. Touch buffers during setup, outside the timed loop.
- **`leaks` vs ASan:** `leaks` finds heap memory nothing points to anymore. ASan catches bad accesses (out of bounds, use after free) when they happen.
- **RAII:** `std::vector` frees itself at end of scope. No `delete`.
- **Naive read bandwidth is 8.03 GiB/s, 5.6% of the 153 GB/s spec.** One `float sum` makes every add wait for the last one, so add latency sets the speed, not memory. The compiler won't split it into SIMD lanes: float addition isn't associative, so reordering changes the result.
